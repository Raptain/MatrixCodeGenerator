\# 🚀 Продвинутый генератор матричных кодов



Веб-приложение для генерации и кастомизации матричных кодов (QR, Data Matrix, Aztec, PDF417) с расширенными возможностями.



\## ✨ Возможности



\### Основные функции

\- ✅ \*\*4 типа кодов\*\*: QR, Data Matrix, Aztec, PDF417

\- ✅ \*\*6 типов данных\*\*: Текст, URL, Контакт (vCard), SMS, Email, Wi-Fi

\- ✅ \*\*Генерация в реальном времени\*\*



\### Кастомизация

\- 🎨 Изменение цвета кода и фона

\- ✨ Градиенты (линейный, радиальный)

\- 🎭 Текстуры (точки, линии)

\- ⭐ Стиль "глаз" для QR кодов

\- 🔷 Изменение формы (круг, сердце, скругленный)

\- 🖼️ Добавление логотипа



\### Дополнительные функции

\- 📥 Экспорт в PNG, SVG, PDF

\- 📜 История кодов с тегами

\- 📊 Аналитика для URL

\- 🌓 Светлая/темная тема

\- 📱 Мобильная адаптация

\- 🔌 API для встраивания

\- 🖼️ Iframe для сайтов



\## 🛠️ Технологии



\- \*\*Backend\*\*: Flask (Python)

\- \*\*Frontend\*\*: HTML5, CSS3, JavaScript

\- \*\*Библиотеки\*\*:

&#x20; - `segno` - генерация матричных кодов

&#x20; - `Pillow` - обработка изображений

&#x20; - `qrcode` - QR коды

&#x20; - `reportlab` - экспорт в PDF

&#x20; - `svgwrite` - экспорт в SVG
